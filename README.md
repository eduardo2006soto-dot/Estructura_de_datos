## 📂 ¿Cómo navegar en este repositorio?

Para revisar la solución de las diferentes prácticas de laboratorio y APEs desarrollados, sigue la estructura de directorios organizada por unidades:

1. **Selecciona la carpeta de la Unidad correspondiente** (ej. `Unidad-1/`, `Unidad-2/`, etc.).
2. **Accede a la carpeta del APE específico** dentro de la unidad (ej. `APE-01/`, `APE-02/`, etc.).

```text
.
├── 📁 Unidad-1/
│   ├── 📁 APE-01/
│   │   └── 📄 Example.md
│   └── 📁 APE-02/
├── 📁 Unidad-2/
│   └── ...
└── 📄 README.md
